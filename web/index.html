Why it's different

Everyone can call a model.

Almost nobody does all of this at once — and nobody does it as a native Mac app running on plans you already own.

No metering

Coral runs on the AI plans you already pay for. No per-token bill on top, no credits, no markup — your cost is your provider's cost.

Your logins, your Mac

No account, no server, no prompt routing. Coral holds no API keys and drives each CLI with your own login. Telemetry is off by default and stays local.

Mix providers per role

Plan with Claude, build with Codex, review with Gemini — inside one orchestrated run. No single-vendor CLI delegates outside its own models.

Reviewer ≠ author

An independent verifier — ideally a different provider family — gates every autonomous loop and can grade an isolated worktree diff before you merge. It runs read-only, so it can't "fix" what it's judging.

Per-line provenance

Every changed line is attributed to the model that wrote it — even when providers took turns on the same file. Autonomous, but accountable by construction.

Native, not Electron

Real SwiftUI on macOS 14+. Idle costs you nothing — nothing animates at rest, ViewModels are evicted, heavy work stays off the main thread. Even the AI labs ship Electron shells for this workflow.

What's inside

Shipped, not roadmap.

Everything below is in the app today, covered by the test suite that gates every change.

Teams & strategies

13 editable topologies — fan-out, planner → implementers → reviewer, debate/consensus, domain specialists, root-cause debugging, solo. An on-device Advisor reads your prompt and recommends one, with the cost band per role.

The Map

Turns any repo — local or a GitHub URL — into an interactive code knowledge graph (deterministic AST, no embeddings), rendered natively. It's injected into the agent's first turn, so the team starts with the structure instead of re-reading files. Estimated token savings shown next to it.

Arena

Head-to-head at three levels: single models, whole teams, and code — where each contestant edits in its own isolated git worktree and you compare diffs. An independent judge scores quality and names a winner, plus the cheaper alternative.

Autonomous loops

Turn, goal, time or proactive loops with a verifiable "done when", a hard turn/spend brake, and a verifier the maker never grades. Optional worktree isolation merges back only on a verified PASS; a webhook (ntfy / Slack / Discord) pings your phone when it finishes.

Code mode & Review

Changed files with per-file +/−, inline diff, stage / commit / branch / push, one-tap Commit + PR and opt-in Auto-PR. One tap runs an independent read-only reviewer over the working diff and lists bugs by severity — with an opt-in "fix them all" that reinjects the findings into the authoring team.

Two-level memory

A cross-project knowledge base of learnings — patterns, decisions, mistakes — each carrying real provenance. Yours and your team's are separate levels: team learnings read as policy and are injected first. Post-run reflection harvests each loop's STATE.md back into the base.

Ship

Deploy from the chat that wrote the code, using deploy CLIs you already have — Vercel, Netlify, Cloudflare wrangler. Coral detects what's installed, runs it in your repo and hands back the live URL. Not a PaaS, no hosting account of ours.

It writes real config

Generate .claude/agents/*.md, an orchestration CLAUDE.md, MCP servers and a runnable dynamic workflow — so the team you designed here also runs in a plain claude session. Portable by construction; no lock-in to leave.

Usage you can see

Real token usage per model from each CLI's local logs, plus your Claude plan headroom — read on-device, never uploaded. Crash and hang diagnostics summarize into a local, exportable log.

The cost lens

Nodes think. Edges are free.

In an agent graph the nodes are model calls — those you pay for. The edges are just data moving between them, and moving data belongs in code, not in another model call. A straight-line chain pays to re-read everything upstream at every hop; a real graph pays once.

Coral shows you the split before you run: paid nodes, free edges, how wide the fan-out actually is, and what the straight-line version would have cost. "No markup" stops being a slogan and becomes a number.

The honest question

"Won't the official app just absorb this?"

Fair — the first-party apps already run parallel sessions. Here's the part a single-vendor product structurally can't ship, and why that's the whole design.

A vendor won't route you to a rival

Cross-provider delegation inside one run — a Claude orchestrator, a Codex implementer, a Gemini reviewer — is a product no single lab can ship, because it means handing work (and spend) to a competitor. Coral is provider-agnostic by construction.

A self-graded verifier isn't a verifier

When the reviewer is the same family as the author it agrees with itself in a different font. Coral's verifier defaults to a different provider family, runs read-only on a fresh context, and grades against a real signal — a test that actually passed.

Open beats a bundled feature

MIT, no account, no server, no telemetry backend. You can read exactly what Coral does with your credentials, fork it, or take the generated .claude/ config and walk away. The exit is part of the product.

And on the terms of service: Coral never carries your subscription tokens into a third-party client. It invokes each provider's official CLI with your own login — the sanctioned path — which is exactly why "your plan, no markup" is possible at all.

How it works

Prompt to running team in three steps.

No setup ritual first. Coral can install and sign into the CLIs for you.

STEP 1

Ask anything

Type your task like any chat and optionally point it at a repo. The Advisor picks the team — one agent or a specialized squad — and shows you what it'll cost before you run it.

STEP 2

Watch the team work

The orchestrator plans, delegates to subagents in parallel and synthesizes — live, with tokens and cost per turn, and each agent's provider on its badge.

STEP 3

Merge it, verified

Work runs isolated in a git worktree. An independent reviewer grades the diff, per-line provenance shows who wrote what, then you merge — or deploy with a CLI you already have.

Where Coral doesn't win. It's a pro-dev tool pointed at your own repo, so there's no hosted deploy pipeline (it drives your deploy CLIs instead) and no browser version. It ships outside the Mac App Store, so first launch uses the normal Gatekeeper allow. Cross-device sync for teams and config works; sync for the memory base is coded but still dormant. And it runs unsandboxed by design — it has to spawn the provider CLIs — which is exactly why the source is open: read SECURITY.md before you trust it.
